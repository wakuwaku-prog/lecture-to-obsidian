一、这个任务在做什么

[PPT原文] 三步：① 看中央，记住外围闪光的位置；② 目标消失后继续注视中央；③ 听到提示后再看向刚才的位置。课件特别强调 The target is absent when the eyes move.（眼睛移动时目标并不在场）——这句是整节课的支点。

[PPT原文] 任务要求「在记住外围目标位置的同时，抑制在听觉提示之前就朝目标做眼跳的冲动」。所以它同时测两件事：记住什么，以及忍住不动。

一句话

记忆引导眼跳把「看不见的记忆」变成「看得见的落点」——你记不住，落点就会偏。

二、为什么要有延迟

[PPT原文] 课件把一次试次切成三阶段：

阶段屏幕上发生什么被试在做什么
ENCODE 编码目标短暂出现保持中央注视
MAINTAIN 维持目标已不可见在延迟中保持它的位置
RESPOND 反应go cue 响起看向记住的位置

[PPT原文] 延迟把任务的三个阶段在时间上分开；课件称这使研究记忆成为可能，并迫使被试脱离外部视觉刺激、依赖内部空间记忆表征。

我的理解

如果没有延迟，被试可以「看着目标直接跳」——那是感觉运动转换，不是记忆。延迟的作用就是把外部线索撤掉，让落点只能来自内部表征。

{{IMG:09 参考资料/附件/L08 课件 PDF/PDF p02.jpg|PDF p2 — ENCODE / MAINTAIN / RESPOND 三阶段|w=720}}

三、怎么把「准不准」拆成三个数

[PPT原文] 课件图示目标 Target (10°, 0°)、眼跳终点 Eye (8°, 1°)，并给出三个定义：

  • 终点 / 绝对误差：终点到目标落点的距离。
  • 方向误差：实际方向与目标方向的角度差。
  • 幅度误差：实际移动距离与所需距离之差。

[PPT原文] 课件称较大的终点误差可以反映记忆噪声（A larger endpoint error can reflect memory noise）。

易错点

「终点误差大 = 记忆差」是课件给的一种解释，不是唯一解释。同一份课件在 p5 就把潜伏期过长归因于「决策困难或认知加工延迟」——同一批数据可以有不同来源的误差，别把落点偏差一律读成记忆问题。

{{IMG:09 参考资料/附件/L08 课件 PDF/PDF p03.jpg|PDF p3 — 终点误差 / 方向误差 / 幅度误差|w=720}}

四、什么时候动：潜伏期与提前眼跳

[PPT原文] 课件把 go cue 设为 0 ms，用曲线对比两类眼动：

  • LATENCY 潜伏期：从 go cue 到眼跳开始的时间。
  • ANTICIPATION 提前眼跳：在 go cue 之前就朝目标做的眼跳。

[PPT原文] p4 的红字补充：Reflecting also the inhibitory control function——潜伏期与提前眼跳也反映抑制控制功能。

这两个指标为什么重要

它们把「忍不住」变成可量化的东西：提前眼跳的比例直接就是抑制控制失败的次数。

五、三类常用指标

[PPT原文] p5 把常用指标归成三栏：

类别指标课件给的解释
Accuracy 准确性绝对误差、方向误差、幅度误差落点与目标的偏离
Latency 潜伏期提示信号出现到眼跳动作开始的时间过长的潜伏期通常反映决策困难或认知加工延迟
Post-delay eye movement 延迟期眼动延迟期间能否保持稳定注视任何偏离都可能反映抑制控制能力或记忆保持的失败

[PPT原文] 口诀行：「幅度看『长短』，方向看『偏向』，终点看『落得准不准』」。

七、三种长时记忆：用同一个情境区分

[PPT原文] p9 用「喝咖啡」这一个情境把三类记忆分开：

类型例子判断依据 Key question
Declarative 陈述性（含 Episodic）I remember drinking coffee with Lin yesterday.What happened, where and when?
Semantic 语义记忆Coffee contains caffeine.What do I know about the world?
Procedural 程序性记忆I can operate the coffee machine.What can I do through practice?

[PPT原文] 课件把程序性记忆注为 Memory of skills and habits；陈述性记忆栏有红字定义 Memories of facts and events that can be expressed in language。

判断依据才是重点

区分三类记忆不看「记的是什么」，而看你能回答哪个问题：何时何地 → 情景；世界事实 → 语义；练习所得 → 程序性。

八、随堂自测

1. 记忆引导眼跳任务把一次试次分成三个阶段，正确顺序是？

答案 A。解析：课件 p2 的三阶段表：ENCODE 目标短暂出现、MAINTAIN 目标已不可见、RESPOND go cue 后允许眼跳。延迟把三者分开，使记忆成为必需。见课件 p2。

2. 眼跳终点落在 (8°, 1°)，目标在 (10°, 0°)。下列哪一项描述的是「终点误差」？

答案 C。解析：课件 p3 给出三个定义：终点/绝对误差＝终点到目标落点的距离；方向误差看角度差；幅度误差看距离差。见课件 p3。

3. 课件把 go cue 设为 0 ms。潜伏期（latency）指的是？

答案 B。解析：课件 p4：LATENCY 是从 go cue 到眼跳开始的时间；ANTICIPATION 是在 go cue 之前就做的眼跳。两者都反映抑制控制功能，但不是同一个指标。见课件 p4。

4. 「I remember drinking coffee with Lin yesterday.」这类记忆，按课件的判断依据应归为？

答案 D。解析：课件 p9 的判断依据：问「何时、何地发生了什么」对应 Episodic，属 Declarative；问世界事实对应 Semantic；问练习所得对应 Procedural。见课件 p9。
