## L08-003 [single] | Latency 潜伏期
课件把 go cue 设为 0 ms。潜伏期（latency）指的是？
EN: The deck sets the go cue at 0 ms. What does latency refer to?

- [ ] A. 目标从出现到消失之间所经历的全部时长
  EN: The full time from target onset to target offset
- [x] B. 从 go cue 到眼跳开始
  EN: From the go cue to saccade onset
- [ ] C. 一次眼跳从启动到结束所花的时间

课件 p4：LATENCY 是从 go cue 到眼跳开始的时间；ANTICIPATION 是在 go cue 之前就做的眼跳。两者都反映抑制控制功能，但不是同一个指标。见课件 p4。
